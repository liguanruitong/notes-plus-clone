# 手写笔记（Notes Plus 风格）

Windows 10 可运行的矢量手写笔记应用（Electron）。灵感来自 [Notes Plus](https://www.notesplus.com/)。

## 已实现功能

- **分屏双开**（v1.8.0）：顶栏「分屏」→「同一笔记」或「打开另一笔记」，右侧用 iframe 再跑一份完整引擎实例，左右可拖分隔条调整比例（各侧最小 20%）；两侧各自独立缩放/平移/翻页互不影响；同一本笔记双开时一侧书写另一侧近实时（<1s）看到更新（BroadcastChannel 跨实例同步 + 主进程广播兜底），书写中不打断、抬手即刷新；右侧为精简子视图，隐藏返回书架/分屏/导入导出等主实例专属入口；关闭分屏恢复占满
- **窗口最小尺寸放宽 + 笔自由选色（hex 输入）+ 卡片自定义大小 + 侧栏卡片列表跳转**（v1.8.0-batch1）

- **丝滑曲线笔触**：采样点之间用二次贝塞尔中点平滑插值渲染，转折/回环处圆滑无折角；只改渲染、不动/不滤波任何原始采样点，笔迹质感保持不变
- **拟物笔盘**：笔 / 荧光笔两种，底部胶囊真实显示，选中的笔上抬；可批量多选一次统一改类型/颜色/粗细
- **透明度 + 压感响应**：每支笔可设笔迹透明度（0–100%）；粗细、透明度各自可开关「响应压感」并单独设响应强度（0–100%）
- **压感手写笔**：线宽/透明度随笔压变化（支持数位板/触控笔的 pointer pressure）
- **扩展纸张尺寸**：向上/下/左/右任意方向把当前页画布向外扩大（长图/宽图），已有笔迹保持原位不动
- **主题色自选**：预设色板 + 取色器自定义任意主题强调色，全应用实时跟随（CSS 变量 `--theme-color`），本地持久化
- **橡皮擦**：整笔擦除 + 像素擦除（笔尖局部挖除）双模式，可调大小
- **套索选择 + 变换框**：框选后旋转 / 缩放 / 移动 / 改色 / 复制 / 删除；复制后自动选中新副本可直接拖动
- **截图笔**：框选任意矩形区域截取画布内容 → 底部预览托盘排成一排 → 点击插入为可拖动缩放的图片，插入后立即选中（直接拖动/缩放放置）；每个预览右上角 × 删除，支持连续截图
- **挖空笔 / 卡片 / 激光笔 / 计算器 / 计时器**：遮挡背诵块、便签、临时高亮、内嵌小工具
- **完全自定义笔盒**：iOS 风开关 + 拖动排序，自由选择哪些工具放进底部笔盒及顺序
- **自定义模板编辑器**：底纹(空白/横线/网格/点阵) + 密度滑块 + 纸色/线色/参考线色取色 + 添加水平/垂直参考线 + 命名保存
- **书架文件夹**：新建 / 命名 / 改色 / 删除文件夹，拖入或移入笔记本，进入 / 返回
- **笔记本封面**：16 色预设 + 自定义取色器
- **调色板 + 自定义取色 + 笔宽调节（1–24）**
- **撤销 / 重做**（每页独立，Ctrl+Z / Ctrl+Y）
- **竖向连续滚动多页**：所有页面在主画布区竖向连续排列，像滚 PDF 一样往下浏览与书写（GoodNotes 风）；侧栏缩略图点击跳转并居中该页，增页 / 删页 / 拖拽重排 / 书签
- **页间间隔可选**：更多面板里 iOS 分段控件切换「无间隔 / 小间隔 / 大间隔」，相邻两页留白可调
- **画布完全自由平移**（v1.7.0）：任何工具下按住空格拖拽、鼠标中键拖拽、平移工具或方向键，都能把画布挪到屏幕任意位置（可把纸张角落拖到正中央），不受居中/滚动边界限制；滚轮平移、Ctrl+滚轮以视口中心缩放
- **复位 / 全览视图**（v1.7.0）：顶栏一键复位居中；一键「全览」缩到看得见全部页的概览再点恢复；双击画布空白处快速复位；顶栏显示「第 X / 共 N 页」页码指示
- **自动保存**到本地（electron-store）
- **导入 / 导出**：图片、PDF、Xournal++ (.xopp)；当前页 PNG/JPG、整本 PDF
- **全操作自定义快捷键**（v1.7.0）：不仅能给每支笔绑键，还能在「更多 → 快捷键设置」给撤销/重做/各工具/翻页/新建页/放大缩小/适应屏幕/复位视图/全览/清空当前页/导出 PDF·PNG 等所有主要动作各绑一个单键；一键全局唯一（笔与动作互斥、冲突自动改绑）、可清除、本地持久化；「快捷键一览」同时列出笔、动作与默认键
- **笔自定义快捷键**：在笔编辑面板给任意笔绑定任意单键（数字/字母），按键即刻切到该笔
- 默认快捷键（未被自定义占用时生效）：`P` 钢笔 / `H` 荧光笔 / `E` 橡皮 / `V` 套索 / `T` 文字 / `1–9` 切笔；空格+拖拽 / 中键拖拽 = 平移；`Esc` 关闭当前弹层

## 与商业版 Notes Plus 的差距（暂未包含）

手写转文字 OCR、录音同步、AI 相关能力。这些需要专门模型/大量工程，属于后续增量。

## 运行（开发）

```bash
npm install
npm start
```

## 打成 Windows exe

在 Windows x64 上：

```bash
npm install
npm run dist:win   # 产物在 release/：便携 exe + 免安装 zip
```

或用本仓库的 GitHub Actions：**Actions → Build Windows exe → Run workflow**，完成后在 Artifacts 下载。打 tag（`git tag v1.2.0 && git push origin v1.2.0`）会自动发 Release。

### 下载建议

Release 提供两种 Windows 产物：

- **推荐 `NotesPlus-win-x64-*.zip`（免安装解压版）**：解压后双击「手写笔记.exe」运行，解压即用、不依赖自解压、绝不会缺 ffmpeg.dll。
- `NotesPlus-portable-*.exe`（单文件便携版）：双击即用；个别机器若因杀毒拦截/临时目录问题导致自解压不完整而报错，请改用 zip 版。
